title: Discord (Lua)
description: Rich presence and OAuth from a Lua client script via mp.discord.
---

The client communicates with the Discord desktop app through `mp.discord`. Client-only.

## Rich presence

```lua title="client.lua"
mp.discord.updateRichPresence('Night City', 'Walking the Glen')
```

`updateRichPresence(state, details)` sets the two text lines. Pass both strings; `''` empties a line. The CyberMP logo and timer stay. Keep the lines short. Call again when the activity changes (job, interior, death).

## OAuth code

```lua title="client.lua"
mp.spawnTask(function()
  while true do
    local code = mp.discord.getCodeAuthorization('YOUR_APP_ID', '["identify"]')
    if code and code ~= '' then
      mp.events.triggerServer('discordCode', code)
      return
    end
    mp.wait(1000)
  end
end)
```

`getCodeAuthorization(appId, scopes)` returns an **authorization code**, not an access token. Send it to **your server** and exchange it with Discord's token endpoint. Do not embed a Discord client secret in the client resource.

The request is asynchronous: the first call starts it and returns an empty string. Call again until the code arrives (a new request is sent at most every 5 seconds). The code is returned once, then the next call returns an empty string again.

`scopes` is a **JSON array** in a string, e.g. `'["identify","guilds"]'` — not a space-separated list. Register the application on the Discord developer portal and use that app id.

`getOAuth2Token(appId)` takes only the app id and returns an **access token** from the Discord Game SDK. It is also asynchronous (empty string until the token arrives), and the SDK is initialized once with the first app id passed.

If Discord is not running, both calls keep returning an empty string. Validate the value before use.
