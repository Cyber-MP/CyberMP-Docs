---
title: Observe (Lua)
description: Observe game methods, execution timing, and Raw variants.
---

`mp.observe(className, methodName, callback)` subscribes a client script to game-method calls. An observer does not replace the method or cancel it by returning a value.

## Setup

Client only. Set `use_game_natives = true` in `resource.toml`. Register hooks once after game classes initialize; see [initialization stages](/lua/client/game-natives).

```toml title="resource.toml"
client_script = 'client.lua'
use_game_natives = true
```

## Registration

```lua title="client.lua"
local settingsMenu = nil

mp.registerGameState('onInit', function()
  mp.observe('SettingsMainGameController', 'OnMenuChanged', function(self)
    settingsMenu = self
  end)

  mp.observe('SettingsMainGameController', 'RequestClose', function()
    settingsMenu = nil
  end)
end)
```

## Arguments

Use the exact class name and REDscript method name from [NativeDB](https://nativedb.red4ext.com/). Select an overloaded method with its full signature, including the suffix after `;`. The parameter name `self` is arbitrary.

- Instance method: `callback(self, arg1, ...)`.
- Static method: `callback(arg1, ...)`, without `self`.
- Observers receive method arguments, not a continuation function or the method result.
- `self` is a weak reference to a game object. A saved controller may no longer be valid after it closes or unloads.

## Execution order

| Call | Capture point | User callback |
| --- | --- | --- |
| `mp.observe` | Before the method | Queued with `mp.setImmediate`, on a later tick |
| `mp.observeBefore` | Before the method | Queued with `mp.setImmediate`, on a later tick |
| `mp.observeAfter` | After the method | Queued with `mp.setImmediate`, on a later tick |
| `mp.observeRaw` | Before the method | Without the `mp.setImmediate` queue |
| `mp.observeBeforeRaw` | Before the method | Without the `mp.setImmediate` queue |
| `mp.observeAfterRaw` | After the method | Without the `mp.setImmediate` queue |

`observe` is the `observeBefore` variant; `observeRaw` is the `observeBeforeRaw` variant. An ordinary `observeBefore` callback can execute after the game method has finished: “before” describes the capture point, not the deferred user code. Observer return values are ignored. Use [Override](/lua/client/overrides) to replace the result.

## Examples

A small synchronous counter: keep network calls, waiting, and expensive work out of a Raw callback.

```lua title="client.lua"
local actionCount = 0
mp.registerGameState('onInit', function()
  mp.observeBeforeRaw('PlayerPuppet', 'OnAction', function(self, action)
    actionCount = actionCount + 1
  end)
end)
```

In `cybermp_core/client/lua/main.lua`, the `VehicleObject.OnVehicleFinishedMounting` observer receives `(self, evt)` and updates the vehicle after mounting. Do not add `wrappedMethod`: that argument belongs to overrides only.

## Cleanup

Registration does not return a public removal id. Hooks are removed automatically when the resource stops or restarts. For temporary disabling, check a flag inside the callback; a disabled override should call its continuation. Register once per resource instance, not on every command or repeated world load.

## Troubleshooting

Check `use_game_natives`, registration stage, class name, full signature, and whether the game calls the method. Start with an observer and a short log message. If replacement behavior differs, check continuation arguments, omit `self` from the continuation call, and return the expected type.
