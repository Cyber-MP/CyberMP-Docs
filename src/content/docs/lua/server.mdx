A `.lua` file in `server_script` (or `shared_script`) runs in the Lua runtime of CyberMP Server. The global `mp` table provides the server API. There is no game layer on the server.

Resource layout: [create a resource](/lua/shared#create-resource). Runtime basics (libraries, `require`, vectors): [shared Lua scripting](/lua/shared).
