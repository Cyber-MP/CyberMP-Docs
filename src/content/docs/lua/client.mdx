A `.lua` file in `client_script` (or `shared_script`) runs in the game process after join, in the Lua runtime. The global `mp` table provides the client API.

- The client Lua API has no entity objects: everything takes numeric ids. Stream events pass `(netID, gameID)`; natives need game ids ([network ids](/lua/client/network-and-local)).
- Game classes and hooks (`Game`, `mp.observe`, `mp.registerGameState`) need `use_game_natives = true` in `resource.toml` ([game natives](/lua/client/game-natives)).
- Call game natives and spawn only after the `onGameLoaded` stage.
