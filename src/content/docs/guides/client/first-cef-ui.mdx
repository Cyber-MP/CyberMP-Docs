import { Steps, Tabs, TabItem } from '@astrojs/starlight/components';

The UI in CyberMP is an HTML page in an embedded browser (CEF). Menus, HUDs, and inventories are HTML, CSS, and JS.

The example sends text from a button to the client script and back.

<Steps>
1. ## Initialize CEF

   Two ways to create a CEF view: `resource.toml`, or the client API.

   > **Important:** Local assets (HTML, CSS, JS) must be listed in the `file` property of `resource.toml`. Otherwise the client does not receive them.

   <Tabs syncKey="cef-init-method">
     <TabItem label="Via resource.toml">
       Add `cef_url` pointing to the local entry HTML. The runtime initializes it when the resource loads.

       ```toml title="resource.toml"
       client_script = './client.js'
       server_script = './server.js'
       cef_url = './ui/index.html'
       file = ["./ui/index.html"]
       ```
     </TabItem>
     <TabItem label="Via client-side API">
       Call `mp.cef.setUrl`. If no CEF instance exists, one is created. The local path must still be listed in the manifest.

       ```toml title="resource.toml"
       client_script = './client.js'
       file = ["./ui/index.html"]
       ```

       ```js title="client.js"
       // Loads a local asset path or an external HTTP address dynamically
       mp.cef.setUrl('./ui/index.html');
       ```
     </TabItem>
   </Tabs>

2. ## HTML page

   Create the UI folder and layout (for example `ui/index.html`). CyberMP injects a global `mp` into the CEF context: [`mp.events.emit`](/reference/browser/api/global/mpevents/#emit) and [`mp.events.on`](/reference/browser/api/global/mpevents/#on).

   ```html title="ui/index.html"
   <!DOCTYPE html>
   <html lang="en">
   <head>
       <meta charset="UTF-8">
       <title>CyberMP Minimal UI</title>
       <style>
           body {
               font-family: Arial, sans-serif;
               color: white;
               background: rgba(0, 0, 0, 0.6);
               display: flex;
               flex-direction: column;
               align-items: center;
               justify-content: center;
               height: 100vh;
               margin: 0;
           }
           button {
               padding: 12px 24px;
               font-size: 16px;
               background-color: #f50057;
               color: white;
               border: none;
               cursor: pointer;
               border-radius: 4px;
           }
       </style>
   </head>
   <body>
       <h1>CyberMP UI Layer</h1>
       <button id="action-btn">Send Data to Client</button>
       <p id="status-text">Awaiting transmission...</p>

       <script>
           const button = document.getElementById('action-btn');
           const status = document.getElementById('status-text');

           // 1. Dispatch an event to the game client when clicking the UI button
           button.addEventListener('click', () => {
               mp.events.emit('uiClickEvent', 'Hello from the CEF browser context!');
           });

           // 2. Listen for response data transmitted from the client script
           mp.events.on('acknowledgeClientData', (payload) => {
               status.innerText = payload;
           });
       </script>
   </body>
   </html>
   ```

3. ## Focus and payloads

   Capture interactions, show the OS cursor, and send data back to the CEF frame.

   ```js title="client.js"
   // Create a command to display the UI and capture input routing priority
   mp.commands.add('ui', (id, args) => {
     // Ensure the URL is correctly set if not using resource.toml initialization
     mp.cef.setUrl('./ui/index.html');

     // Pass keyboard input focus to CEF and display/lock the OS mouse pointer
     mp.cef.setFocus(true, true);

     console.log('UI Focused. Active focus status:', mp.cef.isInFocus());
   });

   // Create a command to clear focus and return control to the game view
   mp.commands.add('closeui', () => {
     mp.cef.setFocus(false, false);
     console.log('UI Unfocused. Active focus status:', mp.cef.isInFocus());
   });

   // Handle incoming events dispatched from the CEF UI layer
   mp.events.onCef('uiClickEvent', (message) => {
     console.log(`[Client Script] Received payload: ${message}`);

     // Send a structured string or layout back down to your web view layout
     mp.events.emitCef('acknowledgeClientData', 'Data received! System synchronized.');
   });
   ```

4. ## Verify

   Connect to the development server.

   1. Press `F8` to open the client console.
   2. Run `ui` to show the HTML overlay. The mouse pointer appears over the game.
   3. Click **Send Data to Client**.
   4. The client console logs the payload. The UI status text updates from the return event.
   5. Run `closeui` to return mouse and keyboard control to the game.
</Steps>

Return value from the server: [RPC](/guides/general/rpc) (`RpcBrowser` + `RpcClient` on the client).
