After the world loads, the local player is not in the scene. Spawn sets health, coordinates, and a console command for recovery.

<Steps>
1. ## Health stats

   Initialize current and maximum health before spawn. The game uses entity IDs and stat modifiers.

   Constants and helpers for `client.js`:

   ```js title="client.js"
   // Health stat pool type - https://nativedb.red4ext.com/e/5923428624360168
   const HEALTH_STAT_POOL_TYPE = 17;
   // Health stat type - https://nativedb.red4ext.com/e/8958699713058621
   const HEALTH_STAT_TYPE = 787;
   // Additive modifier type - https://nativedb.red4ext.com/e/5896876661927857
   const ADDITIVE_MODIFIER_TYPE = 0;

   const setHealth = (value) => {
     const player = mp.game.GetPlayer();
     const playerGameId = player.GetEntityID();
     const statePoolSystem = mp.game.ScriptGameInstance.GetStatPoolsSystem();

     statePoolSystem.RequestSettingStatPoolValueIgnoreChangeMode(
       playerGameId,
       HEALTH_STAT_POOL_TYPE,
       value,
       new mp.game.gameObject(),
       false,
     );
   };

   const setMaxHealth = (value) => {
     const player = mp.game.GetPlayer();
     const playerGameId = player.GetEntityID();

     mp.game.ScriptGameInstance.GetStatsSystem().RemoveAllModifiers(
       playerGameId,
       HEALTH_STAT_TYPE,
       true,
     );

     const newStats = new mp.game.gameConstantStatModifierData_Deprecated();
     newStats.statType = HEALTH_STAT_TYPE;
     newStats.modifierType = ADDITIVE_MODIFIER_TYPE;
     newStats.value = value;

     mp.game.ScriptGameInstance.GetStatsSystem().AddModifier(
       playerGameId,
       newStats,
     );

     const statePoolSystem = mp.game.ScriptGameInstance.GetStatPoolsSystem();

     statePoolSystem.RequestSettingStatPoolValueIgnoreChangeMode(
       playerGameId,
       HEALTH_STAT_POOL_TYPE,
       value,
       new mp.game.gameObject(),
       true,
     );
   };
   ```

2. ## Spawn

   Spawn with `mp.local.spawnPlayer`. The call sets coordinates and starts spawn. It returns `true` if the sequence started. The character may still be absent from the world.

   ```js title="client.js" mark={10}
   const SPAWN_HEALTH = 300;
   // V's apartment
   const DEFAULT_SPAWN_LOCATION = [-1392.637329, 1271.536865, 123.082397, 1];

   const spawnPlayer = (x, y, z, yaw = 1) => {
     setMaxHealth(SPAWN_HEALTH);
     setHealth(SPAWN_HEALTH);

     mp.local.spawnPlayer(x, y, z, yaw);
   };
   ```

3. ## Game load and commands

   Spawn only after `mp.game.onGameLoaded`. Register the console command immediately. It runs when the player types it.

   ```js title="client.js"
   // Automatically spawn when the world loads
   mp.game.onGameLoaded(() => {
     spawnPlayer(...DEFAULT_SPAWN_LOCATION);
   });

   // Register console command
   mp.commands.add('spawn', () => {
     spawnPlayer(...DEFAULT_SPAWN_LOCATION);
   });
   ```

   On connect the local player appears with `300` health near V's apartment. Reset: client console (`F8`), then:

   ```text
   spawn
   ```
</Steps>

## Production notes

Constraints for production spawn. Timeline: [Client lifecycle](/guides/client/lifecycle).

- **`onGameLoaded`, not `resourceStart`.** Do not call `GetPlayer()`, stat pools, or spawn until the world hook fires.
- **Close menus first.** A leftover pause or settings controller freezes input after spawn. Reuse the observers from [teleporting a player](/guides/client/teleporting-player).
- **Wait for the puppet.** `true` from `spawnPlayer` only means the sequence **started**. Poll `mp.game.GetPlayer()` (with a timeout) before health, appearance, or a second teleport.
- **Incomplete gender / `None`.** Right after init the puppet can report no gender. Character-specific meshes and some REDscript calls no-op in that state. Spawn the local player, wait until the puppet exists, then apply appearance.
- **Re-anchor after customization.** Opening the character customization mirror can leave the puppet off the spawn point. Teleport once more after appearance is applied.
- **Natives after load.** Register events and commands immediately. Keep every `mp.game.*` call behind `onGameLoaded`.
