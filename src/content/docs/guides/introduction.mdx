CyberMP is a multiplayer platform for Cyberpunk 2077. You run a dedicated server, players connect to it with the CyberMP client, and what happens on your server (spawning, vehicles, chat, game modes, UI) is decided by scripts you write.

These docs are for people who build servers: scripters and server owners. If you only want to play, you don't need anything here.

## How the pieces fit

| Piece | What it is |
| :--- | :--- |
| **Server** | A standalone program (Windows, Linux or Docker). It accepts connections, keeps players and entities in sync, and runs your server scripts. It is configured with one file, `server.toml`. |
| **Resource** | A folder inside `resources/` that holds one feature or a whole gamemode: scripts, a `resource.toml` manifest and any files the client needs. The server loads the resources you list in `server.toml`. |
| **Server script** | Code that runs on the server. It owns everything players must agree on: who is connected, which vehicles exist, who is allowed to do what. |
| **Client script** | Code that the server sends to each player and that runs inside their game. It can call the game's own functions, so this is where you spawn the local player or change how the game behaves. |
| **Browser UI (CEF)** | An HTML page drawn on top of the game with CEF, the Chromium Embedded Framework. You use it for HUDs, menus and anything else that is easier to build as a web page. |

The three sides talk to each other with events: a client script can send an event to the server and the other way round, and a client script can exchange events with its browser page.

Server and client scripts can be written in **JavaScript** or **Lua**. Both give you the `mp` API (a few functions are named differently between the two), and the examples in these guides come in both. Pick whichever you prefer.
