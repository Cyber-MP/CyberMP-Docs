Server scripts run on the Node.js event loop in CyberMP Server. Global `mp` is `MpServer` ([`@cybermp/server-types`](/guides/general/type-safety)). There is no `mp.game`.

Resource layout: [create a resource](/guides/resources/creating-resource). This section covers `server_script` in JavaScript. A `.lua` server script runs in a separate Lua runtime with its own `mp`: [Lua server scripting](/lua/server).
