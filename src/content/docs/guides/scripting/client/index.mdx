Client scripts run in the game process after join. Global `mp` is `MpClient` ([`@cybermp/client-types`](/guides/general/type-safety)). CEF uses `MpBrowser`.

Call `mp.game` and spawn only after [`onGameLoaded`](/guides/client/lifecycle). Stream events pass `(netID, gameID)`. Natives require game ids ([network](/guides/client/network-and-local)).

A `.lua` client script runs in a separate Lua runtime with its own `mp`: [Lua client scripting](/lua/client).
