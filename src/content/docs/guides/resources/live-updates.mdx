After editing `server.js` or `client.js`, restart that resource. The process stays running.

Requirements:

- running server
- [server console](/reference/server/console)
- a resource, for example `hello_world` from [creating a resource](/guides/resources/creating-resource)

<Steps>
    1. #### Edit the script

        In `resources/hello_world/server.js`:

        ```js title="server.js" ins={2-3}
        console.log('Hello World from CyberMP Server!');
        // New test log:
        console.log("The resource has been updated live!");
        ```

    2. #### Restart the resource

        Console:

        ```shell
        restart hello_world
        ```

        From code: `mp.resources.restart('hello_world')`.

    3. #### Verify logs

        The previous instance stops; the new instance starts with the updated text:

        ```ansi
        [38;2;179;133;0m[00:00:00] [resources][0m Stopped resource hello_world
        [38;2;179;133;0m[00:00:00] [hello_world][0m Hello World from CyberMP Server!
        [38;2;179;133;0m[00:00:00] [hello_world][0m The resource has been updated live!
        [38;2;179;133;0m[00:00:00] [resources][0m Loaded resource hello_world
        >
        ```

</Steps>

`restart` reloads the client script. Connected clients download it again.

File watching instead of manual `restart`: [Hotreload](/guides/general/hotreload).
