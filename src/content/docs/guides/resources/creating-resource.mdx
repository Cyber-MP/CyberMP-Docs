title: Creating resources

---
import { FileTree, Tabs, TabItem, Steps } from '@astrojs/starlight/components';
import { SCRIPT_LANG_TAB_SYNC_KEY } from '../../../../lib/const';

Here you build the smallest useful resource: one script that prints a message in the server console and one that prints a message in the player's game console. It shows the three things every resource needs: a folder, a manifest and an entry in `server.toml`.

You need a server that starts. If you don't have one yet, follow [Getting started](/guides/getting-started) first.

<Steps>

1. ## Create the resource folder

    CyberMP identifies a resource by the name of its folder inside `resources`.

    - Navigate to your server's `resources` folder.
    - Create a new folder named `hello_world`. This is your resource directory, and `hello_world` is the resource's name from now on.

2. ## Configure the resource

    Every resource needs a `resource.toml` file. It tells the server which script to run on the server and which one to send to players.

    - Inside the `hello_world` folder, create a file named `resource.toml`.
    - Paste the following configuration into the file:

    <Tabs syncKey={SCRIPT_LANG_TAB_SYNC_KEY}>
        <TabItem label="JS">
            ```toml title="resource.toml"
            client_script = './client.js'
            server_script = './server.js'
            ```
        </TabItem>
        <TabItem label="Lua">
            ```toml title="resource.toml"
            client_script = './client.lua'
            server_script = './server.lua'
            ```
        </TabItem>
    </Tabs>

3. ## Write the scripts

    <Tabs syncKey={SCRIPT_LANG_TAB_SYNC_KEY}>
        <TabItem label="JS">
            - In the same folder, create two files: `server.js` and `client.js`.
            - Add the following code:

            ```js title="server.js" ins={1}
            console.log('Hello World from CyberMP Server!');
            ```

            ```js title="client.js" ins={1}
            console.log('Hello World from CyberMP Client!');
            ```

            Your folder should now look like this:
            <FileTree>
                - resources
                    - hello_world
                        - server.js
                        - client.js
                        - resource.toml
                - server.toml
            </FileTree>
        </TabItem>
        <TabItem label="Lua">
            - In the same folder, create two files: `server.lua` and `client.lua`.
            - Add the following code:

            ```lua title="server.lua" ins={1}
            print('Hello World from CyberMP Server!')
            ```

            ```lua title="client.lua" ins={1}
            print('Hello World from CyberMP Client!')
            ```

            Your folder should now look like this:
            <FileTree>
                - resources
                    - hello_world
                        - server.lua
                        - client.lua
                        - resource.toml
                - server.toml
            </FileTree>
        </TabItem>
    </Tabs>

4. ## Load the resource

    The server only starts the resources listed in its configuration.

    - Open your `server.toml` (located in the server root directory).
    - Add the folder name to the `resources` array and leave the rest of the file as it is:

    ```toml title="server.toml" ins={2}
    # Names of the resource folders to load, in order.
    resources = ['hello_world']
    ```

5. ## Verify the result

    Start your server. The server script runs while the resource is loading, so its message shows up in the startup logs, prefixed with the resource name:

    ```ansi {4}
    [38;2;179;133;0m[00:00:00] [server][0m CyberMP server starting...
    [38;2;179;133;0m[00:00:00] [server][0m Resources initializing...
    [38;2;179;133;0m[00:00:00] [resources][0m Loaded resource cybermp_core
    [38;2;179;133;0m[00:00:00] [hello_world][0m Hello World from CyberMP Server!
    [38;2;179;133;0m[00:00:00] [resources][0m Loaded resource hello_world
    [38;2;179;133;0m[00:00:00] [server][0m Succesfully binded host 0.0.0.0:2077
    [38;2;179;133;0m[00:00:00] [server][0m Server started
    ```

    The client script runs in the game, so its message never appears in the server console. To see it, connect to the server and press `F8` to open the client console: it shows `Hello World from CyberMP Client!`.

</Steps>
