A minimal resource that writes Hello World to the server and client consoles on start.

<Steps>

1. ## Resource folder

    The server loads directories from `resources`. The folder name is the resource name.

    - Open `resources`.
    - Create a folder named `hello_world`.

2. ## `resource.toml`

    Declares which scripts to run.

    ```toml title="resource.toml"
    client_script = './client.js'
    server_script = './server.js'
    ```

    Additional fields: [`resource.toml`](/guides/resources/resource-toml).

    | Field | Description |
    | --- | --- |
    | `file` | Client files: UI, archives, mods. [Custom assets](/guides/resources/adding-resource-files). |
    | `cef_url` | CEF HTML entry. [CEF UI](/guides/client/first-cef-ui). |
    | `use_game_natives` | `true` when the client calls `mp.game`. |
    | `hot_reload` | Not read by the platform; opt-in flag for the [hotreload](/guides/general/hotreload) watcher example. |

3. ## Scripts

    Next to `resource.toml`:

    ```js title="server.js" ins={1}
    console.log('Hello World from CyberMP Server!');
    ```

    ```js title="client.js" ins={1}
    console.log('Hello World from CyberMP Client!');
    ```

4. ## Enable on the server

    Add the folder name to root `server.toml`:

    ```toml title="server.toml" ins={7}
    tcp_host = "0.0.0.0:2077"
    udp_host = "0.0.0.0:2077"

    connection_host_addr = "127.0.0.1:2077"
    max_players = 20

    resources = ['hello_world']

    disable_voice = false
    ```

5. ## Verify

    Layout:

    <FileTree>
        - resources
            - hello_world
                - server.js
                - client.js
                - resource.toml
        - server.toml
    </FileTree>

    Start the server. Expected log:

    ```ansi {3}
    [38;2;179;133;0m[00:00:00] [server][0m CyberMP server starting...
    [38;2;179;133;0m[00:00:00] [server][0m Resources initializing...
    [38;2;179;133;0m[00:00:00] [hello_world][0m Hello World from CyberMP Server!
    [38;2;179;133;0m[00:00:00] [resources][0m Loaded resource hello_world
    ```

    Join and press `F8`. The [client console](/reference/client/console) shows `Hello World from CyberMP Client!`.

</Steps>
