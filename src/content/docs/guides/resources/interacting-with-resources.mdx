Start, stop, restart, and refresh resources without shutting down the process. Console: [server console](/reference/server/console). Scripts: `mp.resources.start`, `stop`, `restart`, `refresh`.

## New folder not listed

A directory added under `resources` while the process is running is not visible until:

```shell
refresh
```

`refresh` re-scans the disk. Then `start folder_name`. Already running resources are not restarted, but their `resource.toml` is re-read and applies on the next `restart`.

## Start and stop

```shell
start hello_world
stop hello_world
```

```ansi
> stop hello_world
[38;2;179;133;0m[00:00:00] [resources][0m Stopped resource hello_world
```

State from code: `mp.resources.getState('hello_world')` returns a number: `0` not found, `1` starting, `2` started, `3` stopped (or found but never started).

Script edits require `restart`: [live updates](/guides/resources/live-updates).
