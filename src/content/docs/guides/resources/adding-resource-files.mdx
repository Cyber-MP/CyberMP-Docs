---
title: Custom assets
description: Vehicles, weapons, clothing, UI, and archives in a resource.
---

The client receives only paths listed in `file` inside `resource.toml`. Custom vehicles, weapons, and clothing use the same mechanism: archives in `file`, then spawn or equip with the matching [hash](/guides/general/hashes).

```toml title="resource.toml"
file = [
  "./assets/in_world_navigation.archive",
  "./assets/de_dust2/*",
  "./ui/*",
  "./ui/assets/*"
]
```

## Wildcard `*`

`./ui/*` includes every file in that directory. Nested directories are excluded; add `./ui/assets/*` separately, or use `**` (`./ui/**`) to include all nested directories.

## Allowed in `file`

Loaded at client start:

- game files: `.archive`, `.xl`, `.tweak`, `.yaml`, `.yml`, `.redscripts`
- CEF: HTML, CSS, JS

Gameplay scripts belong in `client_script` / `server_script` (JavaScript or Lua). The game loads one compiled redscript bundle, `final.redscripts`. To ship your own, remove `"final.redscript"` from `core.files` and list your `final.redscripts` here, see [redscript](/reference/server/configuration#redscript).

## Packs

| Asset | Files | Script |
| --- | --- | --- |
| Vehicle | `.archive`, ArchiveXL / TweakXL if required | `mp.vehicles.create`: model `tweakdbid` of `Vehicle.…`, appearance `cname` of `default` — [hashes](/guides/general/hashes) |
| Weapon | `.archive`, tweak records (`Items.Preset_…`) | `tweakdbid` in inventory logic |
| Clothing / appearance | `.archive`, appearance names | `cname` of the appearance name — [appearances](/guides/general/appearances) |
| Prop | `.ent` in the game or in an archive | `mp.objects.create`: model `resref` of the `.ent` path — [resource types](/guides/general/resource-types) |
| Pickup | TweakDB item record (`Items.…`) | `mp.pickups.create`: model `tweakdbid` of the record — [resource types](/guides/general/resource-types) |
| CEF UI | HTML, CSS, JS, images | `cef_url` and `file` — [CEF](/guides/client/first-cef-ui) |
