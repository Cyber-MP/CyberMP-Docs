A **plan** is the subscription level of a Server Manager account. It sets the number of servers and Master List extras (avatar, banners, [fast connect](/guides/game-client/fast-connect), [CDN](/guides/dedicated-server/cdn), Discord status). It does not modify the dedicated process or resources.

## Get a plan

1. Subscribe to CyberMP on [Boosty](https://boosty.to/cybermp) or [Patreon](https://www.patreon.com/cybermp).
2. Link that account to Discord. The subscription gives you a role on the CyberMP Discord server.
3. The role sets the level of your Server Manager account automatically. **Benefits** in Server Manager shows the current level.

A server gets the extras of its **owner's** plan. A manager's plan does not matter. Publish with a [Master List token](/guides/server-manager/tokens) in `private_token`.
