Complete resource demonstrating an HTML button that emits to the client. The page does not communicate with the server. `emit` from HTML arrives on the client (`onCef`). List the HTML in `file`. The page gets mouse input only with CEF focus: run `ui` in F8 before clicking.

<TabItem label="client.js">

```js title="client.js"
let focused = false;

// F8: `ui` toggles keyboard focus and the cursor for the page
mp.commands.add('ui', () => {
  focused = !focused;
  mp.cef.setFocus(focused, focused);
});

mp.events.onCef('ui:hello', (text) => {
  console.log('from UI', text);
  mp.events.emitCef('ui:ack', `got: ${text}`);
});
```

</TabItem>
<TabItem label="ui/index.html">

```html title="ui/index.html"
<!doctype html>
<button id="hi">hello</button>
<pre id="out"></pre>
<script>
  document.getElementById('hi').onclick = () => {
    mp.events.emit('ui:hello', 'from cef');
  };
  mp.events.on('ui:ack', (msg) => {
    document.getElementById('out').textContent = msg;
  });
</script>
```
