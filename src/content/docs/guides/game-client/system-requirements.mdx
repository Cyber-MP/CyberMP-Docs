Meet the [Cyberpunk 2077 system requirements](https://support.cdprojektred.com/en/cyberpunk/pc/sp-technical/issue/1556/cyberpunk-2077-system-requirements) (CD PROJEKT RED support). CyberMP adds a launcher, an overlay, [CEF](/guides/client/first-cef-ui), and resource file downloads.

- **GPU / CPU** — equivalent to a loaded single-player session.
- **RAM** — extra for Chromium (CEF) and [custom asset](/guides/resources/adding-resource-files) archives.
- **Disk** — game, CyberMP client, downloaded resource files (UI, `.archive`, mods).
