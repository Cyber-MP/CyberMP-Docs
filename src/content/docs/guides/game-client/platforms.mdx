---
title: Supported platforms
description: Platforms for the CyberMP client and dedicated server.
---

| Component | Platforms |
| --- | --- |
| Game client (launcher + Cyberpunk 2077) | Windows |
| Dedicated server | Windows, Linux (binary or Docker) |
| Consoles, macOS client | Not supported |

The game uses REDengine on Windows. The dedicated server may run on Linux; clients remain Windows.

Steam, GOG, and Epic builds are supported when the patch matches the CyberMP client. Do not mix game versions in one session.

Pirated copies of the game are not supported.
