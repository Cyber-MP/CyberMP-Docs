The CyberMP server is configured with the `server.toml` file. The server reads it, and the `resources` folder, from the directory it is started in.

At runtime, server scripts can read the configuration via `mp.config` in JavaScript or `json.decode(mp.getServerTomlFile())` in Lua. Both contain only the keys that are present in the file, not the defaults.

To see the values the running server actually uses, and whether each one comes from the file or from an environment variable, type [`config`](/reference/server/console) in the server console.

## TOML Schema & Example

To enable autocomplete and property validation in IDEs that support TOML schemas (such as the Even Better TOML VS Code extension), add the schema declaration header at the top of your file:

```toml title="server.toml"
#:schema https://schemas.cyber.mp/server/schema.json

tcp_host = "0.0.0.0:2077"
udp_host = "0.0.0.0:2077"
connection_host_addr = "127.0.0.1:2077"

max_players = 32
private_token = ""

resources = [
  "my_gamemode"
]

disable_voice = false
cef_debug = false
ep2_dlc_enabled = false
duplicatePlayers = 50

[core]
nametags = true
death_autostand = true
disable_switch_seats = true
default_gameplay_restrictions = true
disable_drop_points = true
disable_location_dependent_quests = true
disable_garage = true
delete_map_objects = true
files = []

[core.overrides]
change_player_on_death_logic = true
disable_side_quests_notifications = true
change_vehicles_logic = true
disable_player_inventory_encumbrance = true
player_extended_customization = true
disable_time_skip = true
disable_turrets = true
disable_surveillance_cameras = true
disable_vending_machines = true
disable_generic_devices = true
disable_no_combat = true
```

## Root Configuration Keys

<SchemaTable schema="server" notes={rootNotes} defaults={rootDefaults} />

These keys are accepted by the server but are not in the schema yet, so they are listed by hand:

| Parameter | Type | Required | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| `duplicatePlayers` | `integer` | No | `50` | Maximum connections allowed from a single IP address (anti-DDoS safeguard). |
| `useCdn` | `boolean` | No | `false` | Streams the packed client files from the resource CDN instead of the server itself. Requires the CDN subscription feature; otherwise the server logs a warning and serves files itself. See [CDN](/guides/server/cdn/). |
| `cdnUrl` | `string` | No | `""` | Base URL of the CDN that hosts the packed resource files; used when `useCdn = true`. |

Players need to reach the server over both TCP and UDP, so open both in your firewall.

`tcp_host` and `udp_host` are written as `address:port` with a numeric IP address, for example `0.0.0.0:2077`.

The [official schema](https://schemas.cyber.mp/server/schema.json) requires `tcp_host`, `udp_host` and `resources`. `duplicatePlayers`, `useCdn` and `cdnUrl` are read by the server but are not in the schema yet, so a schema-aware editor may underline them; that warning can be ignored.

## Your own settings

The server ignores keys and tables it does not know, and scripts can read the whole file. That makes `server.toml` a convenient place for your gamemode's settings: add a table of your own and read it when your resource starts.

```toml title="server.toml"
[my_gamemode]
start_money = 750
```

<Tabs syncKey={SCRIPT_LANG_TAB_SYNC_KEY}>
  <TabItem label="JS">
    ```js title="server.js"
    // The table is missing if nobody added it to server.toml, so fall back to defaults.
    const gamemodeConfig = mp.config.my_gamemode || {};

    let startMoney = 500;
    if (typeof gamemodeConfig.start_money === 'number') {
      startMoney = gamemodeConfig.start_money;
    }

    console.log(`New players start with ${startMoney} eddies`);
    ```
  </TabItem>
  <TabItem label="Lua">
    ```lua title="server.lua"
    local serverConfig = json.decode(mp.getServerTomlFile())

    -- The table is missing if nobody added it to server.toml, so fall back to defaults.
    local gamemodeConfig = serverConfig.my_gamemode or {}

    local startMoney = 500
    if type(gamemodeConfig.start_money) == 'number' then
      startMoney = gamemodeConfig.start_money
    end

    print(string.format("New players start with %s eddies", startMoney))
    ```
  </TabItem>
</Tabs>

Things to know:

- You get the file as written, not the effective configuration. A value overridden by an [environment variable](#environment-variable-overrides) still reads as the value from the file, and a key that is absent from the file is absent here, even if the server applies a default.
- A table with no keys in it (a bare `[core]` line, for example) reads as `null`.
- `private_token` is part of the file, so it is readable by every server script. Don't log the whole object.

## Command-line Flags

Launch arguments are executed as console commands with one leading `-` stripped: `-run` runs the `run` command and `--justpack` runs the `-justpack` command.

| Flag | Console name | Description |
| :--- | :--- | :--- |
| `-run` | `run` | Loads `server.toml`, starts `cybermp_core` and every resource listed in `resources`. |
| `--justpack` | `-justpack` | Loads `server.toml` the same way, then writes the packed client files of every started resource (resources marked `server_only` are skipped) plus `connect.json` into `cdn_upload/`, and exits. This is the CDN packaging step; see [CDN](/guides/server/cdn/). |

## Environment Variable Overrides

The root keys of `server.toml` can be overridden with environment variables, without modifying the file. This is useful in Docker containers and CI/CD pipelines.

| Variable | Overrides Key |
| :--- | :--- |
| `CYBERMP_TCP_HOST` | `tcp_host` |
| `CYBERMP_UDP_HOST` | `udp_host` |
| `CYBERMP_CONNECTION_HOST_ADDR` | `connection_host_addr` |
| `CYBERMP_MAX_PLAYERS` | `max_players` |
| `CYBERMP_RESOURCES` | `resources` (comma or space separated list) |
| `CYBERMP_PRIVATE_TOKEN` | `private_token` |
| `CYBERMP_DISABLE_VOICE` | `disable_voice` |
| `CYBERMP_CEF_DEBUG` | `cef_debug` |
| `CYBERMP_EP2_DLC_ENABLED` | `ep2_dlc_enabled` |
| `CYBERMP_DUPLICATE_PLAYERS` | `duplicatePlayers` |
| `CYBERMP_USE_CDN` | `useCdn` |
| `CYBERMP_CDN_URL` | `cdnUrl` |

A key can also be set by its variable alone, without being in the file. The server logs each override at startup, for example `config: tcp_host set from CYBERMP_TCP_HOST`, and the `config` console command shows the variable name in its `source` column.
