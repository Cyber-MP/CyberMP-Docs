У клиента две консоли:

- **консоль F8** в игре — для команд и логов скриптов;
- **консоль разработчика** — отдельное окно с логом клиента.

## Консоль F8

**F8** открывает и закрывает её. В ней выполняются команды, зарегистрированные через `mp.commands.add`, и выводятся логи клиентских скриптов.

### Регистрация команды

<Tabs syncKey="lang">
<TabItem label="JavaScript">

```js title="client.js"
mp.commands.add('spawn', (id, args) => {
  mp.local.spawnPlayer(-1392.637329, 1271.536865, 123.082397, 1);
});
```

</TabItem>
<TabItem label="Lua">

```lua title="client.lua"
mp.commands.add('spawn', function(playerId, args)
  mp.client.spawnPlayer(-1392.637329, 1271.536865, 123.082397, 1)
end)
```

</TabItem>
</Tabs>

Введите имя команды (без `/`) и нажмите Enter:

```text
spawn
```

Клиентские команды выполняются только у локального игрока. Обработчик получает сетевой id локального игрока и аргументы строками. Серверные команды вместо этого получают игрока: [консоль сервера](/ru/reference/server/console#пользовательская-команда).

### Логи

- JavaScript: сюда выводятся `console.log`, `console.warn` и `console.error`. Каждая строка помечается именем ресурса, который её вывел.
- Lua: сюда выводится `print(...)` с именем ресурса. С `use_game_natives = true` он идёт через логгер игрового слоя без имени ресурса ([игровые нативы](/ru/lua/client/game-natives)).

Страницы CEF логируют в консоль Chromium. Включите [`cef_debug`](/ru/reference/server/configuration) в `server.toml` и подключите удалённый отладчик (порт `9222`) для DOM и сети.

### Рабочий цикл

1. F8.
2. Команда (`ui`, `spawn`, `close-menu`).
3. Логи скрипта.
4. Правка файла и рестарт ресурса ([живые обновления](/ru/guides/resources/live-updates) или [hotreload](/ru/guides/general/hotreload)).
5. Повтор команды. Рестарт уничтожает рантайм скрипта ресурса, поэтому старые хуки, тики и обработчики снимаются автоматически.

## Консоль разработчика

Отдельное окно консоли Windows (cmd) с логом клиента. Открывается вместе с игрой, когда в [настройках лаунчера](/ru/guides/game-client/launcher#dev) включена опция **Enable console**. Она предназначена для разработчиков.
