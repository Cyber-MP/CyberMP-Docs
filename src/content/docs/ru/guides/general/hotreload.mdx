Для редких правок выполните `restart` в [консоли](/ru/reference/server/console). Для постоянной правки кода добавьте отдельный ресурс, который отслеживает файлы и вызывает `mp.resources.restart`.

Перезапускается только этот ресурс. Игроки заново скачают его клиентский скрипт. Скриптовый рантайм старого экземпляра уничтожается, поэтому его обработчики `mp.events`, тики, команды и `observe` не переживают перезапуск.

:::note[Freeroam]
В [Freeroam](/ru/guides/freeroam) есть готовый наблюдатель в `resources/hotreload`. Он читает ключ `hotreload = true` (не `hot_reload`), работает только при `NODE_ENV=development`, следит за файлами `client_script` и `server_script` и ищет ресурсы в `./resources` рабочего каталога. При `IS_DOCKER=true` он опрашивает файлы, а не использует события файловой системы.
:::

## Флаг на ресурсе

В `resource.toml` целевого ресурса:

```toml title="resources/hello_world/resource.toml"
client_script = './client.js'
server_script = './server.js'
hot_reload = true
```

Платформа этот ключ не читает; наблюдатель ниже сам читает его из файла и пропускает папки без флага.

## Ресурс-наблюдатель

<Steps>

1. ## Отдельная папка

   Не размещайте наблюдатель в каталоге, который он отслеживает. Иначе перезапуск остановит наблюдение.

   <FileTree>
       - resources
           - hello_world
               - client.js
               - server.js
               - resource.toml
           - hotreload
               - server.js
               - resource.toml
       - server.toml
   </FileTree>

2. ## Только серверный скрипт

   ```toml title="resources/hotreload/resource.toml"
   server_script = ['./server.js']
   ```

   В `server.toml` поставьте его раньше ресурсов, которые он перезапускает:

   ```toml title="server.toml" ins={3}
   resources = [
     'hotreload',
     'hello_world',
   ]
   ```

3. ## Следить за файлами

   Пример на `fs.watchFile`. Запускайте с `NODE_ENV=development`. Не включайте этот наблюдатель на рабочих серверах.

   ```js title="resources/hotreload/server.js"
   const fs = require('fs');
   const path = require('path');

   const debounce = (fn, delay) => {
     let timer;
     return (...args) => {
       clearTimeout(timer);
       timer = setTimeout(() => fn(...args), delay);
     };
   };

   const watchFile = (filePath, onChange) => {
     const run = debounce(onChange, 600);
     fs.watchFile(filePath, { interval: 500 }, () => run());
   };

   const parseHotReload = (content) => {
     const match = content.match(/^hot_reload\s*=\s*(.+)$/m);
     if (!match) return false;
     const raw = match[1].trim().replace(/^["']|["']$/g, '');
     return raw === 'true' || raw === '1';
   };

   const resourcesDir = path.resolve('./resources');

   // Watch only when the server was started with NODE_ENV=development
   const entries = process.env.NODE_ENV === 'development'
     ? fs.readdirSync(resourcesDir, { withFileTypes: true })
     : [];

   for (const entry of entries) {
     if (!entry.isDirectory()) continue;

     const resourcePath = path.join(resourcesDir, entry.name);
     const tomlPath = path.join(resourcePath, 'resource.toml');
     if (!fs.existsSync(tomlPath)) continue;

     const toml = fs.readFileSync(tomlPath, 'utf8');
     if (!parseHotReload(toml)) continue;

     const clientMatch = toml.match(/^client_script\s*=\s*['"](.+)['"]/m);
     const serverMatch = toml.match(/^server_script\s*=\s*(.+)$/m);

     const files = [];
     if (clientMatch) files.push(path.resolve(resourcePath, clientMatch[1]));

     if (serverMatch) {
       const raw = serverMatch[1].trim();
       const list = raw.startsWith('[')
         ? JSON.parse(raw.replace(/'/g, '"'))
         : [raw.replace(/^["']|["']$/g, '')];
       for (const script of list) {
         files.push(path.resolve(resourcePath, script));
       }
     }

     for (const file of files) {
       if (!fs.existsSync(file)) continue;
       console.log(`Hotreload watching ${entry.name}: ${file}`);
       watchFile(file, () => {
         console.log(`[Hotreload] ${file} changed → restart ${entry.name}`);
         mp.resources.restart(entry.name);
       });
     }
   }
   ```

4. ## Запуск

   ```shell
   NODE_ENV=development ./cybermp-server.exe -run
   ```

   PowerShell:

   ```powershell
   $env:NODE_ENV = 'development'
   .\cybermp-server.exe -run
   ```

</Steps>

## Что снять перед restart

`restart` останавливает ресурс и запускает новый экземпляр. При остановке платформа уничтожает скриптовый рантайм: обработчики `mp.events`, циклы `mp.setTick`, команды и хуки `mp.game.observe*` / `override` старого экземпляра снимаются сами. Состояние вне рантайма — нет: например, сущности из `mp.*.create` остаются на сервере, и повторный `create` после рестарта их дублирует. Освобождайте такое состояние в `resourceStop`:

```js title="server.js"
const spawned = [];

mp.events.on('resourceStart', () => {
  spawned.push(mp.vehicles.create({
    model: mp.hashes.tweakdbid('Vehicle.v_standard2_archer_hella'),
    appearance: mp.hashes.cname('default'),
    position: [-1392.6, 1271.5, 123.1],
  }));
});

mp.events.on('resourceStop', () => {
  for (const vehicle of spawned) vehicle.destroy();
});
```

На клиенте: `mp.cef.setFocus(false, false)`, если UI держал курсор.

## Ограничения hotreload

- Новая папка ресурса — сначала [`refresh`](/ru/guides/resources/interacting-with-resources), потом `start`.
- Поменяли `resource.toml` (`file`, `cef_url`, `use_game_natives`) — `restart` его не перечитывает. Выполните `refresh` (он перечитывает манифесты), затем `restart`.
- Игровые `.archive` и `.redscripts` из `file` внедряются при запуске игры. Игрокам нужно перезапустить игру.

Вручную один раз: [живые обновления](/ru/guides/resources/live-updates).
