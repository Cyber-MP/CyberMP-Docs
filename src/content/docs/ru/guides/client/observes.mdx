title: Observe
description: Наблюдение за игровыми методами, порядок вызовов и Raw-варианты.
---

`mp.game.observe(className, methodName, callback)` подписывает клиентский скрипт на вызовы игрового метода. Наблюдатель не заменяет метод и не отменяет его возвращаемым значением.

## Подготовка

Только клиент. Укажите `use_game_natives = true` в `resource.toml`. Зарегистрируйте хуки один раз после инициализации игровых классов; [стадии инициализации](/ru/reference/client/working-with-game-natives).

```toml title="resource.toml"
client_script = 'client.js'
use_game_natives = true
```

## Регистрация

```js title="client.js"
let settingsMenu = null;

mp.game.onInit(() => {
  mp.game.observe('SettingsMainGameController', 'OnMenuChanged', (self) => {
    settingsMenu = self;
  });

  mp.game.observe('SettingsMainGameController', 'RequestClose', () => {
    settingsMenu = null;
  });
});
```

## Аргументы

Передайте точное имя класса и REDscript-имя метода из [NativeDB](https://nativedb.red4ext.com/). Для перегруженного метода используйте полную сигнатуру с суффиксом после `;`. Имя переменной `self` произвольное.

- Метод экземпляра: `callback(self, arg1, ...)`.
- Статический метод: `callback(arg1, ...)` — без `self`.
- Наблюдатель получает аргументы метода; функция продолжения и результат метода ему не передаются.
- `self` — слабая ссылка на игровой объект. Не считайте сохранённый контроллер действительным после его закрытия или выгрузки.

## Порядок выполнения

| Вызов | Момент перехвата | Пользовательский обработчик |
| --- | --- | --- |
| `mp.game.observe` | До метода | В очереди `setImmediate`, на последующем тике |
| `mp.game.observeBefore` | До метода | В очереди `setImmediate`, на последующем тике |
| `mp.game.observeAfter` | После метода | В очереди `setImmediate`, на последующем тике |
| `mp.game.observeRaw` | До метода | Без очереди `setImmediate` |
| `mp.game.observeBeforeRaw` | До метода | Без очереди `setImmediate` |
| `mp.game.observeAfterRaw` | После метода | Без очереди `setImmediate` |

`observe` — вариант `observeBefore`; `observeRaw` — вариант `observeBeforeRaw`. У обычного `observeBefore` обработчик может выполниться уже после завершения игрового метода: «до» описывает момент перехвата, а не выполнение отложенного кода. Возвращаемое значение любого наблюдателя игнорируется. Для замены результата используйте [Override](/ru/guides/client/overrides).

Если метод вызван из другого потока, мост сначала переносит обработчик в поток скрипта. Поэтому даже `Raw` не гарантирует синхронность относительно каждого игрового вызова. Используйте `Raw` только когда знаете контекст вызова.

## Примеры

Лёгкий синхронный счётчик: не выполняйте сеть, ожидание или тяжёлую работу внутри Raw-обработчика.

```js title="client.js"
let actionCount = 0;
mp.game.onInit(() => {
  mp.game.observeBeforeRaw('PlayerPuppet', 'OnAction', (self, action) => {
    actionCount += 1;
  });
});
```

В Freeroam `menus.service.ts` хранит контроллеры через `SettingsMainGameController.OnMenuChanged` / `RequestClose`; `loading-screen.service.ts` наблюдает `LoadingScreenSystem.OnLoadingScreenStateChange`; `appearance-menu.service.ts` сочетает `observeRaw` и `observeAfter`. Эти наблюдатели отслеживают состояние, не заменяя методы.

## Очистка

Регистрация не возвращает публичный id для снятия хука. При остановке или перезапуске ресурса его хуки снимаются автоматически. Для временного отключения проверяйте флаг внутри обработчика; в отключённом override вызывайте продолжение. Регистрируйте хуки один раз на экземпляр ресурса, а не на каждом вызове команды или повторной загрузке мира.

## Проверка проблем

Проверьте `use_game_natives`, стадию регистрации, имя класса, полную сигнатуру и факт вызова метода игрой. Начните с наблюдателя и короткого сообщения в журнале. Если замена не сохраняет поведение, проверьте аргументы `wrappedMethod`, отсутствие `self` в вызове продолжения и возвращаемый тип.
