**План** — уровень подписки аккаунта Server Manager. Он задаёт число серверов и опции Master List (аватар, баннеры, [быстрое подключение](/ru/guides/game-client/fast-connect), [CDN](/ru/guides/dedicated-server/cdn), статус в Discord). На выделенный процесс и ресурсы не влияет.

## Как получить план

1. Оформите подписку CyberMP на [Boosty](https://boosty.to/cybermp) или [Patreon](https://www.patreon.com/cybermp).
2. Привяжите этот аккаунт к Discord. Подписка выдаёт роль на Discord-сервере CyberMP.
3. Роль сама выставляет уровень вашего аккаунта Server Manager. Текущий уровень показан в разделе **Benefits** в Server Manager.

Сервер получает опции плана своего **владельца**. План менеджера не учитывается. Публикация — [токен Master List](/ru/guides/server-manager/tokens) в `private_token`.
