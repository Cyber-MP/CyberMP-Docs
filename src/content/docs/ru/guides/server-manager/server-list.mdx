Список серверов — публичный список серверов CyberMP. Игроки видят его в разделе **Servers** [лаунчера](/ru/guides/game-client/launcher) и на [cyber.mp/servers](https://cyber.mp/servers), выбирают сервер и заходят на него.

## Как сервер попадает в список

1. Создайте сервер в [Server Manager](/ru/guides/server-manager/create-server) на сайте CyberMP. Вы получите [токен](/ru/guides/server-manager/tokens).
2. Запишите токен в `private_token` в `server.toml`. В `connection_host_addr` укажите адрес, по которому подключаются игроки.
3. Запустите сервер. Он отправляет свой адрес в список при старте и затем каждые 2 минуты.

При каждом heartbeat бэкенд запрашивает `http://<connection_host_addr>/info`, то есть по HTTP на TCP-порт сервера. Из ответа он берёт число игроков онлайн и число слотов (`max_players`). Сервер, который перестал отправлять heartbeat, выпадает из списка примерно через 2 минуты.

Название, описание, аватар, баннер и другие поля карточки задаются в Server Manager, а не в `server.toml`.

Список отсортирован по [плану](/ru/guides/server-manager/subscriptions) владельца сервера: сначала Diamond, затем Gold, затем все остальные. Внутри уровня выше серверы с большим числом игроков.

Выключенная **Public Visibility** в Server Manager скрывает сервер из списка. Ссылка [быстрого подключения](/ru/guides/game-client/fast-connect) при этом работает.

## Сервера нет в списке

- `private_token` пустой, от другого сервера или сброшен в Server Manager.
- Владелец сервера забанен.
- Адрес в блок-листе CyberMP.
- `http://<connection_host_addr>/info` недоступен из интернета: `0.0.0.0`, `127.0.0.1` или закрытый TCP-порт. Если ключ пустой, сервер отправляет `127.0.0.1`.
- `/info` сообщает больше игроков, чем `max_players`.
- Выключена **Public Visibility**.
- Сервер не запущен.

На сервер, которого нет в списке, всё равно можно зайти по адресу: [прямое подключение](/ru/guides/game-client/direct-connect).
