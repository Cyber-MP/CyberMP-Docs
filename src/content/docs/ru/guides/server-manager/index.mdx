**Server Manager** на [manager.cyber.mp](https://manager.cyber.mp) регистрирует запущенный выделенный процесс в Master List. Вход через Discord.

| Раздел | Что в нём |
| --- | --- |
| **Servers** | Ваши серверы и серверы, где вы менеджер. **Create new...** → **Server** создаёт карточку. |
| **Benefits** | [Планы](/ru/guides/server-manager/subscriptions) и ваш текущий уровень. |
| **Settings** | Язык интерфейса и удаление аккаунта. |

На странице сервера три вкладки:

| Вкладка | Что в ней |
| --- | --- |
| **Settings** | **Display**: имя, описание, аватар, баннер. **Metadata**: игровой режим, язык, теги, сайт. **Control**: видимость в списке, [быстрое подключение](/ru/guides/game-client/fast-connect), баннер подключения. |
| **Statistics** | История онлайна и пик за 24 часа. Gold и выше. |
| **Manage** | Менеджеры (Silver и выше, добавляет владелец), [приватный токен](/ru/guides/server-manager/tokens), удаление сервера. |

Карточка появляется в [списке серверов](/ru/guides/server-manager/server-list) лаунчера и на [cyber.mp/servers](https://cyber.mp/servers).

Локальный `127.0.0.1` не требует Server Manager.
