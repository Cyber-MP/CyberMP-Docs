Готовые каталоги ресурсов. Поместите их в `resources`, добавьте имя в `server.toml`, войдите и выполните команду в F8.

Первый запуск: [введение](/ru/guides/getting-started).

| Рецепт | Команда | Демонстрирует |
| --- | --- | --- |
| [Транспорт](/ru/guides/recipes/spawn-vehicle) | `car` | `tweakdbid`, `cname('default')` |
| [Дроп](/ru/guides/recipes/drop) | `drop` | `.ent` через `resref` |
| [NPC](/ru/guides/recipes/npc) | — (спавн при старте) | Пед + синхронная meta |
| [RPC hello](/ru/guides/recipes/rpc-hello) | `ping` | `callServer` / `register`, одно `name` |
| [Кнопка CEF](/ru/guides/recipes/cef-button) | `ui` (фокус) | HTML `emit` → клиент `onCef` |

Сбои: [диагностика](/ru/guides/general/troubleshooting). Карта `mp`: [карта API](/ru/guides/general/api-map).
