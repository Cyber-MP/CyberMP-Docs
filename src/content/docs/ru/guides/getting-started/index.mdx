CyberMP — мультиплеерная платформа для Cyberpunk 2077. Клиенты подключаются к выделенному серверу. Игровая логика реализуется **ресурсами**: каталогами JavaScript или Lua, которые загружает сервер.

| Раздел | Содержание |
| --- | --- |
| Клиент | Настройка игрового клиента: платформы, системные требования, настройки лаунчера, прямое подключение, быстрое подключение, консоль F8 |
| Сервер | Хостинг выделенного сервера: железо и ОС, `server.toml`, команды консоли, CDN для файлов ресурсов |
| Server Manager | Регистрация сервера, токены доступа, планы и размещение в Master List |
| Концепции | Хеши и модели, `resource.toml`, кастомные ассеты, жизненный цикл клиента, измерения, синхронизация и meta, решение проблем |
| JavaScript и Lua | API `mp` на обоих языках, в разделах с одинаковой структурой: скрипты сервера, скрипты клиента, общие скрипты |
| Рецепты | Примеры ресурсов |
| Справка | TypeDoc из `@cybermp/server-types`, `client-types`, `browser-types` |
