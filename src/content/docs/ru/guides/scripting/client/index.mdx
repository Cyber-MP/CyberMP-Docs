Клиентские скрипты выполняются в процессе игры после входа. Глобальный `mp` — `MpClient` ([`@cybermp/client-types`](/ru/guides/general/type-safety)). CEF использует `MpBrowser`.

Вызывайте `mp.game` и спавн только после [`onGameLoaded`](/ru/guides/client/lifecycle). События стрима передают `(netID, gameID)`. Нативам нужны game id ([сеть](/ru/guides/client/network-and-local)).

Клиентский скрипт `.lua` выполняется в отдельной среде Lua со своим `mp`: [скрипты клиента на Lua](/ru/lua/client).
