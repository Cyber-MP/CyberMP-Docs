Серверные скрипты выполняются на event loop Node.js в CyberMP Server. Глобальный `mp` — `MpServer` ([`@cybermp/server-types`](/ru/guides/general/type-safety)). `mp.game` отсутствует.

Раскладка ресурса: [создание ресурса](/ru/guides/resources/creating-resource). Этот раздел описывает `server_script` на JavaScript. Серверный скрипт `.lua` выполняется в отдельной среде Lua со своим `mp`: [скрипты сервера на Lua](/ru/lua/server).
