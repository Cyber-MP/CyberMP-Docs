---
title: Платформы
description: Платформы клиента и выделенного сервера CyberMP.
---

| Компонент | Платформы |
| --- | --- |
| Игровой клиент (лаунчер + Cyberpunk 2077) | Windows |
| Выделенный сервер | Windows, Linux (бинарник или Docker) |
| Консоли, клиент macOS | Не поддерживаются |

Игра работает на REDengine под Windows. Выделенный сервер может работать на Linux; клиент остаётся Windows.

Сборки Steam, GOG и Epic поддерживаются при совпадении патча с клиентом CyberMP. Не смешивайте версии игры в одной сессии.

Пиратские копии игры не поддерживаются.
