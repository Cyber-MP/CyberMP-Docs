Лаунчер CyberMP показывает список серверов, запускает Cyberpunk 2077 с клиентом мультиплеера и подключает к выбранному серверу. Он обновляется сам.

## Разделы

| Раздел | Что показывает |
| --- | --- |
| **Servers** | Публичный [список серверов](/ru/guides/server-manager/server-list). Над ним счётчики **Servers**, **Players** и **Peak players**, поле **Search** и фильтры **Players**, **Full** и **Empty**. |
| **Favorites** | Серверы, которые игрок сохранил. |
| **History** | Серверы, на которые игрок заходил раньше. |
| **Settings** | Настройки лаунчера, см. ниже. |
| **About** | Сведения о лаунчере. |
| **Direct connect** | Кнопка внизу меню. Подключение по адресу, см. [прямое подключение](/ru/guides/game-client/direct-connect). |

## Настройки

Настройки лаунчера хранятся на ПК игрока и действуют на всех серверах. Владелец сервера ими не управляет.

Клиентские скрипты читают настройки в виде JSON через `mp.getLauncherSettings()`. В столбце **Ключ** указано поле JSON, которое читает игровой клиент. Прочерк значит, что клиент не читает поле для этой опции.

### General

| Настройка | Ключ | Что делает |
| --- | --- | --- |
| Nickname | `username` | Имя игрока. Его видят другие игроки и серверные скрипты. Если поле пустое, берётся имя пользователя Windows. |
| Language | — | Язык интерфейса лаунчера. |

### Audio

| Настройка | Ключ | Что делает |
| --- | --- | --- |
| Voice chat | `voiceChatEnabled` | Включает голосовой чат. Опции ниже доступны, только пока он включён. |
| Push to talk | `pushToTalk` | Микрофон передаёт звук, только пока зажата клавиша. |
| Push to talk key | `pushToTalkKey` | Клавиша push-to-talk. |
| Device input / Device output | `audioInputName` / `audioOutputName` | Микрофон и устройство воспроизведения. |
| Input volume / Output volume | `audioInputVolume` / `audioOutputVolume` | Громкость микрофона и воспроизведения. |

### Other

| Настройка | Ключ | Что делает |
| --- | --- | --- |
| Game location | `gameLocation` | Путь к `Cyberpunk2077.exe`. Кнопка **Browse** выбирает файл. |
| GPU accelerated cef | `cefSharedTexture` | Браузерный интерфейс в игре ([CEF](/ru/guides/client/first-cef-ui)) передаётся игре через общую текстуру GPU, а не копией в памяти. |
| Auto close after connected | — | Закрывает лаунчер после подключения игры к серверу. |
| Im edgerunner! | — | Пока не описана. |
| Clear cache | — | Очищает кэш лаунчера. |
| Reset settings | — | Возвращает настройки по умолчанию. |

### Dev

Эти опции для разработчиков.

| Настройка | Ключ | Что делает |
| --- | --- | --- |
| Player gender | `gender` | Мужское или женское тело стандартного персонажа, которого игрок получает при входе на сервер. |
| Local server host | — | Адрес локального сервера для разработки. По умолчанию `127.0.0.1:2077`. |
| Disable RTX | `disableRtx` | Запускает игру без NVIDIA DLSS, Frame Generation, Reflex и NIS: их библиотеки не копируются в игру. |
| Enable console | — | Открывает отдельное окно консоли (cmd) с логом клиента. См. [консоль разработчика](/ru/reference/client/console#консоль-разработчика). |
