Быстрое подключение (fast connect) — ссылка для входа на сервер из [Master List](/ru/guides/server-manager/server-list). Ссылка имеет вид `https://c.cyber.mp/<id>`. Игрок открывает её в браузере, лаунчер CyberMP запускается сам и подключает игрока к этому серверу. Адрес вводить не нужно.

Быстрое подключение — функция [подписки](/ru/guides/server-manager/subscriptions): оно доступно начиная с плана Bronze.

Это не [прямое подключение](/ru/guides/game-client/direct-connect). Прямое подключение — вход по `host:port`, введённому вручную; оно работает для любого сервера, в списке он или нет.

## Как включить

Быстрое подключение включается в [Server Manager](/ru/guides/server-manager), в карточке **Control** на странице сервера, а не в [`server.toml`](/ru/reference/server/configuration).

| Опция | План | Что делает |
| --- | --- | --- |
| Fast Connection | Bronze | Включает ссылку. **Preview** показывает страницу ссылки. |
| Fast Connection URL | Gold | Свой id для `https://c.cyber.mp/<id>`. Он должен быть уникальным. Ниже Gold id генерируется: 8 случайных символов. |
| Fast Connection Banner | Gold | Фон веб-страницы ссылки. |

**Connection Banner** в той же карточке — другое изображение: фон, который игроки видят во время подключения к серверу. На Bronze можно загрузить статичное изображение, на Gold анимированное.

Игровому серверу нужен только [токен Master List](/ru/guides/server-manager/tokens) этой карточки в `private_token`. Сервер читает значения быстрого подключения из Master List при старте и при каждом heartbeat (примерно раз в 2 минуты), поэтому изменения в Server Manager доходят до запущенного сервера без перезапуска.

Ссылка работает, только пока сервер отправляет heartbeat. Выключенная **Public Visibility** скрывает сервер из списка, но ссылку не отключает.

## Что нужно игроку

Установленный лаунчер CyberMP. Браузер передаёт ссылку лаунчеру, а лаунчер запускает игру с адресом сервера.

Страница сервера на [cyber.mp/servers](https://cyber.mp/servers) работает так же: **Play** открывает лаунчер через `cybermp://connect?id=<id сервера>`, а кнопка «поделиться» копирует ссылку быстрого подключения, если оно включено.

## Статус в Discord

Сервер отправляет каждому подключающемуся клиенту данные карточки для статуса игрока в Discord:

| План | Что отправляет сервер |
| --- | --- |
| Silver и выше | Имя, аватар и баннер сервера. |
| Gold и выше, быстрое подключение включено | Ещё fast connect id и баннер для кнопки входа. |

На планах ниже сервер эти поля не отправляет.
