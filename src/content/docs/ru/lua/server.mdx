`.lua`-файл из `server_script` (или `shared_script`) выполняется в среде Lua на CyberMP Server. Глобальная таблица `mp` предоставляет серверный API. Игрового слоя на сервере нет.

Структура ресурса: [создание ресурса](/ru/lua/shared#create-resource). Основы среды (библиотеки, `require`, векторы): [общий скриптинг Lua](/ru/lua/shared).
