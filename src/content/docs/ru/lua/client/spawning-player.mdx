После загрузки мира локального игрока нет в сцене. Спавн задаёт координаты, а консольная команда позволяет восстановиться.

<Steps>
1. ## Включите игровой слой

   Он нужен для игровых стадий и вызовов `Game.*`:

   ```toml title="resource.toml"
   client_script = 'client.lua'
   use_game_natives = true
   ```

2. ## Спавн

   `mp.client.spawnPlayer(x, y, z, yaw)` задаёт координаты и запускает спавн. Возвращает `true`, если последовательность запущена. Персонажа в мире может ещё не быть.

   ```lua title="client.lua"
   -- V's apartment
   local DEFAULT_SPAWN = { -1392.637329, 1271.536865, 123.082397, 1 }

   local function spawnPlayer(x, y, z, yaw)
     mp.client.spawnPlayer(x, y, z, yaw or 1)
   end
   ```

3. ## Загрузка мира и команды

   Спавн — только в стадии `onGameLoaded`. Консольную команду регистрируйте сразу. Она выполнится, когда игрок её введёт.

   ```lua title="client.lua"
   -- Automatically spawn when the world loads
   mp.registerGameState('onGameLoaded', function()
     spawnPlayer(table.unpack(DEFAULT_SPAWN))
   end)

   -- Register console command
   mp.commands.add('spawn', function()
     spawnPlayer(table.unpack(DEFAULT_SPAWN))
   end)
   ```

   При подключении локальный игрок появляется у квартиры V. Сброс: консоль клиента (`F8`), затем:

   ```text
   spawn
   ```
</Steps>


## Ограничения

Стадии и их порядок: [игровые нативы](/ru/lua/client/game-natives#стадии).

- **`onGameLoaded`, а не `resourceStart`.** Не вызывайте `Game.GetPlayer()` и спавн до этой стадии.
- **Сначала закройте меню.** Оставшийся контроллер паузы или настроек замораживает ввод после спавна. Используйте наблюдатели из [телепорта игрока](/ru/lua/client/teleporting-player).
- **Дождитесь пупета.** `true` от `spawnPlayer` значит только, что последовательность **запущена**. Опрашивайте `Game.GetPlayer()` в задаче с `mp.wait` (с таймаутом) перед здоровьем, внешностью или повторным телепортом.
- **Неполный пол / `None`.** Сразу после инициализации пупет может не иметь пола. Меши для конкретного персонажа и часть вызовов REDscript в этом состоянии ничего не делают. Заспавните локального игрока, дождитесь пупета, затем применяйте внешность.
- **Переставьте после кастомизации.** Зеркало кастомизации персонажа может сдвинуть пупет с точки спавна. После применения внешности телепортируйте ещё раз.
- **Нативы после загрузки.** События и команды регистрируйте сразу. Все вызовы `Game.*` — после `onGameLoaded`.
