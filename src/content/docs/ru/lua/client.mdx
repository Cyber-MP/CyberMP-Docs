`.lua`-файл из `client_script` (или `shared_script`) выполняется в процессе игры после входа, в среде Lua. Глобальная таблица `mp` предоставляет клиентский API.

- В клиентском Lua API нет объектов сущностей: всё принимает числовые id. События стрима передают `(netID, gameID)`; нативам нужны игровые id ([сетевые id](/ru/lua/client/network-and-local)).
- Игровым классам и хукам (`Game`, `mp.observe`, `mp.registerGameState`) нужен `use_game_natives = true` в `resource.toml` ([игровые нативы](/ru/lua/client/game-natives)).
- Игровые нативы и спавн вызывайте только после стадии `onGameLoaded`.
