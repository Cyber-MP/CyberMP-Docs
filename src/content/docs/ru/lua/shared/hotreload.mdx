Для редких правок выполняйте `restart` в [консоли сервера](/ru/lua/server/resources#console) ([живые обновления](/ru/lua/server/live-updates)). Для постоянной правки используйте ресурс-наблюдатель, который вызывает `mp.resources.restart`.

Hotreload перезагружает **только этот ресурс**. Подключённые клиенты заново скачивают его клиентские скрипты. Старое состояние Lua закрывается, поэтому его обработчики событий, задачи, таймауты, колбэки `mp.onUpdateLoop` и игровые хуки не переносятся.

## Флаг на ресурсе

Задайте `hot_reload` в `resource.toml` нужного ресурса. Платформа этот ключ не читает; его читает из файла наблюдатель и пропускает папки без флага:

```toml title="resources/hello_world/resource.toml"
client_script = 'client.lua'
server_script = 'server.lua'
hot_reload = true
```

## Ресурс-наблюдатель

Автоматическое отслеживание файлов требует отдельного ресурса-наблюдателя; сама среда Lua файлы не отслеживает. Настройте наблюдатель на чтение путей скриптов и флага `hot_reload` из `resource.toml` и вызов `mp.resources.restart` при изменении отслеживаемого файла. Описанная здесь конфигурация отслеживает следующие пути:

- `server_script`: один путь или массив.
- `client_script`: только один путь в кавычках. Массив не отслеживается.
- `shared_script` и другие файлы не отслеживаются. После их правки выполните `restart` вручную.

## Очистка перед перезапуском

Сущности, созданные через `mp.*.create`, остаются на сервере после закрытия старого состояния, и перезапуск, который создаёт их снова, их дублирует. Удаляйте их в `resourceStop`:

```lua title="server.lua"
local spawned = {}

mp.events.add('resourceStart', function()
  spawned[#spawned + 1] = mp.vehicles.create({ --[[ … ]] })
end)

mp.events.add('resourceStop', function()
  for _, vehicle in ipairs(spawned) do
    if vehicle.exist then vehicle:destroy() end
  end
end)
```

Не используйте `mp.wait` в обработчике `resourceStop`: состояние закрывается сразу после него. На клиенте снимите фокус CEF, если интерфейс держал курсор.

## Ограничения hotreload

- Новые **папки** ресурсов по-прежнему требуют [`refresh`](/ru/lua/server/resources) (или перезапуска сервера) перед `start`.
- Изменения самого `resource.toml` — `file`, `cef_url`, `use_game_natives`, `export` — `restart` не перечитывает. Выполните `refresh` (он перечитывает манифесты), затем `restart`.
- Игровые архивы и `.redscripts` из `file` подключаются при запуске игры. Чтобы их подхватить, игрокам нужно перезапустить игру.
